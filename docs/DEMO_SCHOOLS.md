# Pumba demo schools

Pumba's development database retains three fictional schools for realistic
manual testing and Demo screenshots:

- Brackenmere Community School (`brackenmere`): a smaller secondary-school
  dataset suitable for basic teacher and technician workflow checks.
- Ashwick Hall School (`ashwick`): a larger dataset with post-16 class-code
  conventions for timetable and planning checks.
- Fenmere Academy (`fenmere`): a dense dataset suitable for technician
  filtering, printing, and higher-volume timetable checks.

These are existing database fixtures. The fictional-school generator that
created them has completed its purpose and is no longer part of Reqsheet.
Do not regenerate, reset, or delete these organisations when testing. No
credentials or protected host configuration are stored in this repository.
